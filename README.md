# Vue 3 + TypeScript + Vite

# US 1: Navegación del Catálogo

Como jugador de FIFA, quiero ver una lista clara de todos los regates disponibles para poder elegir cuál quiero aprender o consultar.

Criterios de Aceptación:

La vista principal muestra tarjetas (cards) por cada regate.

Cada tarjeta incluye el nombre del regate y la cantidad de estrellas de filigranas requeridas.

El diseño se adapta a escritorio (grilla/paneles) y a móvil (columna única).

# US 2: Detalle del Movimiento (GIF e Inputs)

Como jugador que está practicando, quiero ver el GIF del regate en bucle junto con los controles exactos para memorizar el timing del movimiento.

Criterios de Aceptación:

Al seleccionar un regate, se despliega su vista en detalle sin recargar la página.

El GIF se reproduce en bucle continuo de forma automática.

Los inputs (botones) se muestran de forma gráfica (iconos de flechas, joysticks, botones).

Existe un toggle o botón para alternar entre controles de PlayStation y Xbox.

# US 3: Filtrado Contextual Rápido

Como jugador en medio de un partido, quiero filtrar los regates con un solo clic (por estrellas o situación) para encontrar la solución rápida sin perder de vista el juego.

Criterios de Aceptación:

Los filtros deben ser botones de un solo clic (Ej: "5 Estrellas", "1v1", "Salida rápida"), sin menús desplegables complejos.

La lista de tarjetas se actualiza instantáneamente al aplicar un filtro.
